# Anandhu Aniyan — Professional Profile

Static personal profile and resume website designed for GitHub Pages.

## Intended URL

`https://anandhuaniyan.github.io`

## Contents

- `index.html` — professional profile
- `styles.css` — responsive light/dark design
- `script.js` — theme, mobile navigation, reveal effects
- `assets/Anandhu_Aniyan_Resume.pdf` — downloadable resume
- `robots.txt` and `sitemap.xml` — basic search-engine readiness
- `404.html` — custom error page
- `.nojekyll` — serves the site as plain static files

## GitHub Pages

Use a public repository named `anandhuaniyan.github.io`, place these files on the default branch, and publish Pages from the repository root.
